Что такое API ?

Application Programming Interface

API (Интерфейс программирования приложений) — это набор правил, протоколов и инструментов, которые позволяют различным программным приложениям обмениваться данными и функциями друг с другом.

Посредник Мост Интерфейс Протокол

Простые примеры из жизни

Как API работает в реальном мире

🍽️

Ресторан

Официант (API) передает ваш заказ (запрос) на кухню (сервер) и приносит еду (ответ). Вы не заходите на кухню сами — это роль API!

Клиент → API → Сервер
🏦

Банкомат

API банка позволяет мобильным приложениям проверять баланс, переводить деньги и получать выписки без прямого доступа к базе данных.

Защищенный доступ
✈️

Поиск авиабилетов

Агрегаторы используют API авиакомпаний для получения актуальных цен, расписаний и наличия мест в реальном времени.

Real-time данные
🌤️

Погодное приложение

Приложение отправляет запрос к API погодного сервиса и получает JSON с температурой, влажностью, ветром и прогнозом на неделю.

JSON формат
💳

Платежный шлюз

Интернет-магазины используют API платежных систем (Stripe, PayPal) для обработки транзакций без хранения данных карт.

Безопасные платежи
📱

Вход через соцсети

Сайты используют OAuth API Google/Facebook для аутентификации пользователей без создания новой учетной записи.

OAuth 2.0
